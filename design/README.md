## v2.1 改动（回应“太像 PPT”）

1. **首页不再是一摞静态卡片**：
   - 能力行 hover 整行反色 + 右侧出现「→」，是可点的导航，不是摆设；
   - 案例区改为**横向滚动流**（6 卡循环、悬停暂停、右端渐隐 + SCROLL/DRAG 提示条）——这是网页语言，不是 PPT 语言；
   - 首屏、SLA 表、能力区底部都有显式「→ /NETWORK」「→ /CAPABILITY」**路由链接**。
2. **路由架构**：一个首页 + 4 个路由页（/capability、/network、/cases、/about），首页只做叙事钩子，详情进路由页。见 S0 板。
3. **/network 服务网络页（N1）**：左侧覆盖地图，右侧信息卡。
   - 地图底图接入**腾讯地图 GL JS**（合规数据源，国界线由官方数据渲染，避免手绘版图风险；WorkBuddy 预览环境走本地代理免 key）；
   - 图层：800km 覆盖圈（MultiCircle）、已建/在建点位（MultiMarker）、脉冲扩散动画；
   - 悬停/点击任意服务点，右侧信息卡即时切换（定位、覆盖、到场时效）；
   - 无法联网时自动降级为「坐标网格 + 覆盖圈」示意图，交互保留。

## 本版改了什么

1. **全站黑白**：去掉所有彩色，只剩一套中性灰阶（#0A0A0A → #FFFFFF）。层次靠字重、字号、1px 线和留白建立，不靠颜色。
2. **白底为主**：默认浅色，深色模式由同一套 CSS 变量反相得到，切换不丢结构。
3. **品牌绿 #A9CB39 只出现在右下角切换按钮**：这是你要求的试验点。确认方向后，可以只给「主 CTA 悬停态 + 表单焦点框」加这个绿色，主体仍然黑白。
4. **内容全部来自宣传册 PDF**：维修成功率 99.2%、芯片级修复 85%+、算力恢复 98%+、SLA 三档、28 城、ISO 三体系、真实案例数据等，未编造。
5. **首屏右侧换了视觉逻辑**：不再是 SaaS 看板，而是一张**维修工单**（编号 / 设备 / 故障 / 修复轨道 / 压测指标）。黑白体系下，等宽字体的工单比彩色图表更贴行业，也更高级。

| 层级 | 字号 | 字重 | 字距 | 行高 |

拉丁字母与所有数字统一走等宽字体（`ui-monospace / SF Mono / Menlo`）——这是黑白体系里唯一「有质感」的元素，它负责工程可信度。
中文：`PingFang SC / HarmonyOS Sans SC`。
